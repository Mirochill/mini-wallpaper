# Changelog

Notable Mini Wallpaper changes are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-05-30

### Added

- Native WPF animated wallpaper playback behind desktop icons.
- Local MP4, WMV, AVI, MOV, and animated GIF support.
- Notification-area controls for wallpaper selection, playback, startup, and
  exit.
- Automatic FFmpeg optimization with resolution limiting, `30 fps` playback,
  audio removal, and deterministic caching.
- Per-user installation script and startup registration.
- Public documentation, contribution guide, security policy, and MIT License.
- Windows GitHub Actions build verification.
- Vivid README hero artwork.
